## Transcription rules used in every file

- `PRINTED:` = every printed word on the page, in order, including headings, table cells, captions, page numbers, citations.
- `HANDWRITTEN:` = every pen mark, verbatim spelling/punctuation as written (even if ungrammatical), with location (top/right/bottom/margin), ink description, and shapes (circle, arrow, underline, tick, bracket, cross).
- `[photo-cropped]` = text cut off by camera frame, not by document.
- `[uncertain: ...]` = best reading of hard handwriting, flagged, never guessed silently.
- `INSTRUCTION:` = what the professor is ordering, in plain words.
- Nothing is paraphrased away. Nothing is skipped because it is inconvenient.
