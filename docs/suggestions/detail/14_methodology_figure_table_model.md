```
MPS-post_it = β0 + β1 EPS_it + β2 DPS_it + β3 BVPS_it + β4 ROA_it + ε_it    (1)
```
Para (variable definitions under equation):
```
where MPS-post_it represents the closing market price observed at the pre-specified post-disclosure trading date for bank i in fiscal year t. EPS_it, DPS_it, BVPS_it, and ROA_it denote earnings per share, dividend per share, book value per share, and return on assets, respectively. The parameter β0 represents the intercept, β1 through β4 represent regression slope coefficients capturing the estimated conditional association between each regressor and MPS-post holding the other included variables constant, and ε_it is the stochastic disturbance term.
```
